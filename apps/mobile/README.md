# MargWatch Mobile App (Android)

## 📱 **FOR ANDROID DEVELOPER ONLY**

This directory contains the Android mobile application for MargWatch.

### **Quick Start**
```bash
cd mobile-app
./gradlew assembleDebug
./gradlew installDebug
```

### **Development**
- **Language**: Kotlin
- **Architecture**: MVVM + Clean Architecture
- **UI**: Jetpack Compose
- **Networking**: Retrofit + OkHttp

### **Key Files**
- `app/src/main/java/com/margwatch/` - Main source code
- `app/src/main/res/` - Resources (layouts, strings, etc.)
- `build.gradle.kts` - Build configuration

### **Integration Points**
- Backend API endpoints
- Firebase FCM notifications
- Google Maps integration
